# 🍅 A Tomato Leaf Disease Classifier Model

## 📌 Overview
The **Tomato Leaf Disease Classifier** is a deep learning-based project that classifies tomato leaf images into **eight categories** to detect plant diseases early. This helps farmers take preventive measures to protect their crops and improve agricultural yield.

## 📂 Dataset
- **Source:** [PlantVillage Dataset on Kaggle](https://www.kaggle.com/datasets/emmarex/plantdisease)
- **Categories:**
  - Bacterial Spot
  - Early Blight
  - Late Blight
  - Leaf Mold
  - Septoria Leaf Spot
  - Spider Mites
  - Target Spot
  - Healthy

## 🏗️ Tech Stack
- **Programming Language:** Python
- **Libraries:** TensorFlow, Keras, OpenCV, NumPy, Matplotlib
- **Frameworks:** Gradio, Hugging Face Spaces
- **Deployment:** Hosted on **Hugging Face Spaces**

## 🚀 Features
- Uses **CNN (Convolutional Neural Networks)** for classification
- Achieves **~88% accuracy** on test data
- Provides **real-time image classification** for tomato leaves
- Hosted and accessible on Hugging Face Spaces with **Gradio UI**

## 📊 Model Performance
- **Accuracy:** ~88%
- **Loss:** Optimized using Adam Optimizer
- **Evaluation Metrics:** Precision, Recall, F1-score

## 🌱 Future Improvements
- Expand to include **other plant species**
- Improve accuracy with **transfer learning (e.g., ResNet, EfficientNet)**
